01 / REASONING

智能体如何思考、规划与使用工具？

5 篇精读

ReAct 把推理、行动和观察连起来，Reflexion 引入文字反思；LATS 与 RAP 进一步比较搜索和内部推演，Toolformer 则学习何时调用外部工具。读这一组，重点分清模型生成的推理、真实环境反馈与训练时的工具学习。

R1 - ReAct 光想不查容易产生幻觉，光做不想又缺乏规划——把“思考、行动、观察”连成闭环，让智能体边查证事实边调整方向。
R2 - Reflexion 做错了重来一遍，为什么还会踩同一个坑？不用更新模型权重，而是把失败原因写成自然语言“错题本”留在记忆里，指导下一轮尝试。
R3 - Language Agent Tree Search (LATS) 一条检索轨迹走偏了，其他尝试还能留着吗？把蒙特卡洛树搜索、模型价值评估和语言反思结合起来，比较多个候选分支。
R4 - Reasoning via Planning (RAP) 没法在真实环境里反复试错，怎么办？让大模型同时扮演“推理者”与“内部世界模型”，在脑海中用树搜索推演未来状态与长远回报。
R5 - Toolformer 怎样学会什么时候该调用工具？用少量示例让模型在语料中采样调用，执行后按后续文本的预测损失筛选，再做微调。

02 / EVALUATION

一次成功之外，怎样检验真实交互中的表现？

3 篇精读

τ-bench 检验对话、工具调用与业务规则下的任务完成，τ²-bench 加入用户也能操作环境的双控制协作；可靠性研究再检查一致性、鲁棒性、可预测性与安全性。关注的不只是某次成功，而是重复运行和条件变化下的表现。

R6 - τ-bench 能聊天的客服未必守得住业务红线——让智能体在多轮用户对话、数据库读写与复杂行业规则之间周旋，用 pass^k 看看多次运行是否一致。
R7 - τ²-bench 用户不只提问，还得亲手操作手机配合排障，智能体该怎么引导、怎么同步状态？用“双控制”环境找出多轮协作卡在哪里。
R8 - Science of AI Agent Reliability 为什么平均准确率涨了，智能体到了关键生产场景还是让人不放心？不只看一个均值，从一致性、鲁棒性、可预测性与安全性四个角度看看可靠性。

03 / MEMORY

怎样存下经历，并在需要时找回？

5 篇精读

Generative Agents 用经历支撑连贯行为，MemGPT 调度有限窗口与外部存储；HippoRAG 用图索引连接跨段证据，Zep 处理事实的时间变化，A-MEM 让记忆关联与语境持续演化。比较它们存什么、怎样组织、何时更新，以及如何召回。

R10 - Generative Agents 怎样让智能体过上真实可信的日常，而不是机械复读角色设定？用记忆流记下经历、用定期反思提炼高阶洞见、用层级规划安排小镇社交。
R11 - MemGPT 历史超过窗口后，怎样留下关键事实并找回旧事？借鉴虚拟内存，让模型用函数调用来管理当前工作区、对话历史和归档存储。
R12 - HippoRAG 两个证据段落都在库里，怎么还会漏掉一段？离线抽取关系并建立图索引，查询时用个性化 PageRank 传播查询信号，再汇总成段落分数。
R13 - Zep 用户的现实情况变了，旧记忆该怎么处理？把情节、语义与社区放进三层动态图谱，再用双时态时间轴（T 与 T′）追踪事实的生效与失效。
R14 - A-MEM 新经历来了，旧经历往往也有了新的意义——借鉴卢曼“卡片盒笔记法”，让新记忆入库时自主连接相关旧卡片，并反过来更新旧卡片的语境描述。

04 / CONTEXT

怎样让长历史与经验进入下一次决策？

4 篇精读

先用 LongMemEval 和 PersonaMem 检查长历史取用与个性化回应，再看 ACE 的增量行为手册，以及 Voyager 的可检索技能库。共同的问题是：哪些信息值得进入当前上下文，哪些经验能在下一次任务中复用？

R16 - LongMemEval 当对话跨越数百场会话，记忆系统到底卡在“没存好”、“没找准”还是“没读懂”？用五大核心记忆能力评测，看看建库、检索与阅读各环节的得失。
R17 - Know Me, Respond to Me (PersonaMem) 能背出用户的历史设定，就等于懂用户吗？在偏好看起来随时间变化的长期交互里，分清“认出用户画像”与“给出真正贴合当下处境的回应”。
R15 - ACE 一次失败怎样变成下一次可用的经验？让执行、反思与策展各管一件事，只对行为手册做增量更新，保住具体策略，再看看反馈质量与持续适应的真实代价。
R18 - Voyager 会说铁镐配方，为什么还不能从空背包做出来？在 Minecraft 中按现场状态自动选任务，照着反馈修改执行程序，再把成功技能存成可检索、可组合的代码。

05 / WORLD MODELS

学会预测动作后果，怎样帮助行动与交互？

2 篇精读

DreamerV3 从真实经验学习世界模型，在想象中训练策略，再回到环境行动；Genie 从视频学习潜在动作，生成可交互环境。重点分清真实观测、模型预测与策略学习，避免把想象成功当成真实成功。

R51 - DreamerV3 空背包怎样走到钻石？沿 Minecraft 案例拆开世界模型、想象轨迹与 Actor–Critic 学习，再核对跨领域固定配方，以及“曾找到钻石”与单局成功率的区别。
R52 - Genie 只看角色移动、不知道玩家按键，怎样学出可操作的世界？沿平台跳跃案例拆开动作瓶颈、视频 tokenizer 与动力学模型，再用 CoinRun 检查动作能否迁移。
